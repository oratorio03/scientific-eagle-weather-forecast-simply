SkyView Fix Automatico

Corregge automaticamente il repository GitHub. Devi solo incollare un token.

Passo 1: Ottieni il token (30 secondi)

  1. Apri questa pagina: github.com/settings/tokens/new
  2. In "Note" scrivi: SkyView Fix
  3. Spunta solo "repo" (per modificare i tuoi repository)
  4. Clicca "Generate token" in fondo
  5. Copia il token (stringa che inizia con ghp_)

Passo 2: Incolla il token e clicca Fix
